LocalFix - Local Business Service Portal

LocalFix is a responsive web-based Local Business Service Portal developed as a Web Development Internship Project.

Project Description

LocalFix allows users to browse local services, submit service requests, and track their submitted requests using a unique Request ID.

Features

- Responsive design for desktop and mobile devices
- Easy navigation between different sections
- Local service listing
- Service booking/request form
- Client-side form validation
- User-friendly error messages
- Automatic Request ID generation
- Request status tracking
- Request data stored using browser localStorage
- Mobile-friendly interface

Services Available

- Plumbing
- Electrical Repair
- Home Cleaning
- AC Repair

Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- GitHub Pages

How It Works

1. Open the LocalFix website.
2. Browse the available services.
3. Select a service.
4. Fill in the service request form.
5. Submit the request.
6. A unique Request ID is generated.
7. Use the Request ID in the Track Request section to view the submitted request.

Validation

The application validates:

- Full name
- 10-digit Indian phone number
- Service selection
- Problem description

If the entered information is invalid, appropriate error messages are displayed.

Limitation

Request information is stored using browser localStorage. Therefore, request data is available only in the same browser and device where the request was submitted.

For a production-level application, a backend server and database can be added.
